## 买之前必须确认的三件事

**第一，区域对得上。** 这是硬门槛，不是建议。卡在哪个国家或地区发行，就只能充进那个区域的 Apple Account。美区卡进不了中国区账号，中国区发行的卡也不能运到中国以外使用。你在美国亚马逊买卡送给一个用中国区账号的朋友，他连兑换都做不到。

**第二，收礼人有一个能正常登录的 Apple Account。** 兑换要登录账号，余额直接进账号，没有账号这张卡就是串字符。送之前问一句对方账号是哪个区的，比事后扯皮省事。

**第三，卡买了就不能退。** 美国亚马逊和沙特亚马逊的商品页都写明 Apple Gift Card 不支持退货退款，除法律要求外不可转售、不可兑现、不能在 Apple 转售商处兑换。面额买大了，只能自己慢慢花。

## 怎么送：在 App Store 里直接发卡

送礼品卡不用去别的地方，iPhone 或 iPad 上打开 App Store，点右上角头像，选 **Send Gift Card by Email**，按提示填收件人、面额、留言和送达时间就行。

如果你送的是具体某个 app、某首歌或某本书，路径不一样：在 App Store、iTunes Store 或 Books 里找到那个商品，点分享按钮里的 Gift，再按屏幕提示个性化并发送。收礼人收到邮件、点里面的 Redeem，商品会自动下载到他的设备。

Mac 或 Windows PC 上送礼，要在 Apple Music app 里打开 iTunes Store（Windows 直接开 Apple Music app），找到商品，点价格旁的分享按钮，选 Gift This [商品类型]。

这里有个大多数人不知道的细节：**赠送商品时，费用记在你绑定的付款方式上，不会扣你的 Apple Account 余额。** 你账上躺着一百美元余额，送朋友一个付费 app，扣的还是你的信用卡。想用余额送礼，只能先买礼品卡再让对方自己兑换。

礼物发出去对方没收到，可以重发。iPhone 上进设置 → 点你的名字 → Media & Purchases → View Account → Gifts，选中那个礼物，核对收件人邮箱拼写，点 Resend Gift。列表里看不到 Resend Gift，说明对方已经兑换过了。电脑端在 Account Settings 的 Purchase History 里找 Manage Gifts，点 Edit 重发。

## 赠送功能的限制清单

下面这些限制来自 Apple 支持文档，都是实际操作时会撞上的：

- 账号开了家人共享、并且启用了“购买前询问”（Ask To Buy），不能购买礼物
- 部分地区不支持赠送礼物，商店可用性也按国家或地区不同
- iPhone 或 iPad 不能赠送单曲，要送歌得用 Mac 或 Windows PC
- Mac 或 Windows PC 不能赠送 app，要送 app 得用 iPhone 或 iPad
- Mac、Windows PC，以及 iOS 17.2 / iPadOS 17.2 / tvOS 17.2 及以上的设备，不能赠送电影或电视节目
- 免费 app 不能赠送，只能分享链接
- 想取消礼物，要在预定送达时间前最多两天联系 Apple 支持

跨区赠送的限制也在这份清单的逻辑里：收礼人的账号必须和你在同一个国家或地区，否则送不出去。

## 兑换之后，钱在哪里

兑换完成或主动充值后，资金会进到 Wallet 里的 **Apple Account card**。打开 Wallet 就能看当前余额和历史消费记录，在 Apple Store 或 App Store 付款时直接走这笔钱。

Apple 提供两个官方入口：一个是 Redeem，用来兑换卡上的代码；一个是 Add money，用来主动给账号充值。两个入口都在 apple.com 体系内，需要登录你的 Apple Account。

余额能覆盖的范围比很多人以为的宽：App Store 的 app 和游戏、Apple Music、Apple TV、Apple Arcade、Apple Books、Apple News+、iCloud+、Fitness+、Apple One，以及 Apple Store 零售店、Apple Store app 和 apple.com 上的商品。美国版条款里明确写了“Not valid for other payments”，也就是说它不能拿来还信用卡、不能转账给别人、不能当通用支付工具。

## 有效期和退款，别想当然

**退款：明确不行。** 美国亚马逊和沙特亚马逊两个渠道都写了不支持退货退款，也不可在 Apple 转售商处兑换或兑现。Apple 不对未经授权的使用负责，发卡主体是美国版条款里的 Apple Value Services, LLC。

**有效期：没有全球统一答案。** 沃尔玛的 FAQ 写明，在沃尔玛购买的 Apple Gift Card 不过期、没有附加费，随时可以兑换。这是沃尔玛平台的说法，属于零售渠道口径。另一边，Apple 中国官网仍挂着一份中国区礼品卡条款，写着自购买之日起三年有效、仅限中国区使用、不可运输到中国以外地区。两份表述的适用地区和卡种不同，别拿一个地区的规则套另一个地区。

实际操作上，拿到卡先看购买页面的条款或卡背说明，确认有效期和适用区域，再决定是一次性充进去还是留着慢慢用。充进 Apple Account 余额之后就是余额了，不再受卡本身有效期的约束。
